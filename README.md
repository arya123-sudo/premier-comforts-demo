# Hotel Premier Comforts — Demo Website

A demo website built for **Hotel Premier Comforts**, Jalahalli Cross, Bengaluru.

**Live demo:** https://arya123-sudo.github.io/premier-comforts-demo/

The rooms, tariffs and details shown on this page are sample placeholders, to be replaced with the hotel's actual rooms and rates. The demo highlights the hotel's 1,299 Justdial ratings, a "Book Direct & Save" direct-booking angle, and WhatsApp booking enquiries on every room.
